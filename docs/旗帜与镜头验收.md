# 旗帜与镜头收尾

## 旗帜

旗杆保持固定，旗面从固定边到自由边逐渐增加摆幅。横向波动叠加小幅上下起伏，两船保留少量相位差；航速增加时，摆幅和传播速度随之增加。变形后的法线一起更新，避免旗面动了、光照仍像平板的情况。

旗帜与划桨、敲鼓共用航行时间。按空格暂停或拖动鼠标观察时，动作同时暂停。顶点变形在 `shaders/phong.vert` 中实现，OBJ 的原始旗杆和旗面仍保留。

运行时旗面以旗杆轴线为中心转向船尾（船体局部 -X）。原始网格保持 +X 的建模参考姿态，朝向矩阵同时用于主画面与阴影通道；船体转弯时，旗面随船体坐标系一起转向，波动仍由固定边向自由边传播。

## 26 秒镜头

| 时间 | 画面安排 |
|---|---|
| 0～4 秒 | 古镇与河道建立镜头，展示两船起步 |
| 4～10 秒 | 镜头逐渐靠近，进入河心低空跟拍，从门楼下方通过 |
| 10～17 秒 | 跟拍中段竞争，展示两队划桨、鼓手动作和青队提速 |
| 17～22 秒 | 镜头升高，交代两船进入弯曲河道的运动方向 |
| 22～26 秒 | 向后、向侧面拉远，将河湾、古镇和田野纳入收尾画面 |

相机位置由独立的分段三次 Bézier 曲线计算，没有固定在船上。相邻段共享速度，起点和终点的速度为零，使起飞和收尾更平缓。注视点来自两船的实际位置，视场角随阶段变化；近景必要时沿观察方向平滑后退，避免为容纳船尾而使用过大的广角，并为两船及左上角操作提示留出画面空间。

初始龙舟位置与播放起点已统一，按空格开始时不会先把龙舟跳回上游。按 2 可检查当前选中的龙舟，按 3 回到动画镜头，按 C 可退出跟随；自由相机与模型键盘控制继续保留。

镜头代码位于 `src/cinematic.h` 和 `src/main.cpp`。建模阶段的路线草图保留作参考，当前程序的实际采样结果以 `results/cinematic_samples.csv` 为准。

## 验收方式

1. `test.bat` 检查旗面固定边、自由边运动、航线连续性、船桨与鼓槌周期、船速积分和部件分类。
2. `bin/DragonBoat.exe --verify` 在真实 OpenGL 窗口中运行输入和绘制检查，保存 36 张截图，包含材质对比、鼠标观察、两船键盘选择、划桨、敲鼓、旗帜近景及各阶段镜头。
3. `bin/DragonBoat.exe --playthrough` 从开始到结束实际绘制完整 26 秒动画，逐帧检查 OpenGL 错误和龙舟构图边界，保存六个时间点的画面。
4. `tools/audit_cinematic_scene.py` 使用最终 Blender 场景的建筑、屋顶、桥、地形、河岸、水面与河床进行射线检查。检查覆盖 1,561 个相机采样和 12,488 条船头、船尾、船体及旗帜观察射线，并检查相机附近的碰撞与两船的河岸间隙。透明树叶未作为不透明障碍加入此项检查。
5. `tools/verify_runtime_results.py` 汇总截图、连续播放日志及几何检查结果，写入 `results/runtime_validation.json`。

几何检查同时保存相机采样文件的 SHA-256，汇总时核对文件一致性。完整播放日志为 `results/playthrough.log`，六张连续播放截图为 `playthrough_0.png` 至 `playthrough_5.png`。这些是程序实绘结果，不是 Blender 离线效果图。

当前显示版已加入实时方向光投影与四倍 MSAA。旗帜与水面使用解析动画，未求解布料或流体动力学。

## 本机验收结果

- 场景、键鼠与各项动画的 32 张运行检查图通过，OpenGL 错误数为 0。
- 连续播放实际绘制 302 帧，动画时间运行到 26 秒；包含截图开销的检查过程耗时约 29.0 秒。六个截图检查点全部保存。
- 相机按 60 Hz 检查 1,561 个位置，12,488 条观察射线未发现建筑、桥梁、地形或河岸遮挡检查点。相机到所查场景表面的最小间隙约 3.25 米，龙舟包围范围到河岸的最小余量约 1.02 米。
- 补查了空格暂停、鼠标观察暂停及 Tab 选择青队后的独立键盘控制，均通过。

验收中修正了门楼遮挡、下降和转弯时船尾靠近画面边缘的问题，并减弱、打散了过于规则的尾流泡沫。
