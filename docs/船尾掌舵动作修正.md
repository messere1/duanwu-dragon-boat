# 船尾掌舵动作与穿模修正

原场景中的舵手与舵桨是静态装配，没有接入动作更新；旧舵桨还向船身内倾。当前程序将旧节点作为静态参考保留，运行时替换为站姿 IK 动作和一支向船尾外侧伸出的长桨。

## 当前动作

- 双脚保持在船尾平台，肩背和双臂随掌舵动作调整，避免整个人僵站不动。
- 上下手使用同一支刚性长桨上的两个握点，手腕的位置和朝向同步跟随。握点在弯曲手指围成的空间内，不再把手腕骨端直接放在桨杆中心。
- 舵桨独立使用 steering_oar.obj：上端横柄恢复为直径 24 毫米的圆截面，握持段桨杆直径约 24.6 毫米；调整了手指关节角度，使双手能包住桨柄。
- 两队使用错开的动作相位，单周期 4.2 秒；暂停比赛时，舵手和长桨一起暂停。
- 桨杆避开身体与船舷，桨叶朝船尾外侧入水，水下部分按现有水面深度遮挡。
- 这是与比赛时间同步的掌舵表现；龙舟的航线继续由 Bézier 路径决定，未增加舵力驱动的动力学求解。

## 模型与源文件

- models/helmsman_steering.blend：可编辑的舵手骨架、双手 IK、长桨和局部船尾参考。时间轴 1–127 帧，30 fps，首尾闭合。
- models/steering_cycle.bin：40 帧固定拓扑姿态数据，运行时插值。
- models/steering_samples.csv：实际烘焙后掌内握持定位点，供 C++ 对照握点。
- models/steering_cycle.json：姿态与 IK 误差记录。
- models/steering_grasp.json：手掌握持坐标系、指节角度和接触定位点。
- models/steering_hand_indices.json：实际导出网格中参与掌部接触检测的三角面索引。
- src/steering.h 与 tools/steering_motion.py：运行端与制作端的同一掌舵轨迹参数。
- tools/bake_steering_cycle.py、save_steering_authoring.py：动作制作与导出。

完整环境场景中的舵手仍为建模阶段的静态参考。查看、修改本轮动作请打开 helmsman_steering.blend；实际动画结果以 OpenGL 程序为准。

## 检查

C++ 测试将 41 组烘焙掌内握点与运行端的桨柄握点逐一比对，同时检查旧静态舵手、旧舵桨被替换。实际掌部 IK 最大误差小于 0.1 毫米。

几何审计检查 80 个插值姿态：对两艘船的船身和船尾装饰做三角面相交检测，并对桨杆与身体表面做距离及射线检测。身体避让检查不包含握持区域，该区域另以专门的手部表面检查覆盖；同时核对双脚顶点是否移动。可编辑 Blender 文件也检查多个时间点的手掌与桨柄对位。

手部检查对 160 个插值姿态中的左右手掌、手指三角面求到握柄轴的保守距离，接触区没有豁免。当前最小表面间隙约 0.17 毫米，最大约 0.74 毫米，未检测到握柄穿入。它检查几何接触，不模拟软组织压缩或握力。

对应记录为 results/steering_collision_audit.json、steering_grip_audit.json、steering_ik_audit.json、steering_authoring_validation.json。新增的 results/verify_34.png 和 verify_35.png 展示两个不同相位的舵手近景。

第一次运行会重建 scene-v6.bin 缓存，以便排除旧静态节点；无需删除原有模型文件。

整段比赛另以 60 Hz 检查两队共 3,122 个实际 C++ 航行位置，对完整舵桨网格与码头、石岸、桥、河岸、河床做三角面相交检查；记录见 results/steering_environment_audit.json。

握持近景见 results/steering_grip_closeup.png（可编辑源文件的工作台预览）；运行时效果见 verify_34.png、verify_35.png。重新制作时依次运行 build_steering_grip.py、fit_steering_hands.py、bake_steering_cycle.py，再运行三项几何审计和源文件检查。
