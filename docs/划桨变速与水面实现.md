# 划桨、变速与水面效果

## 动作依据

龙舟队员朝船头坐，用单叶桨向后拉水。动作依次为伸桨入水、拉水、提桨出水和空中回桨。同一条船由领桨带节奏，不能把左右两侧做成交替划动，也不能让桨叶始终泡在水里来回摆。

本次采用以下资料作为依据：

- [FCRCC 龙舟技术手册，Alan Carlsson](https://dragonboat.it/wp-content/uploads/2014/05/false-creek-db-manual.pdf)：参考握桨、身体前倾、入水、出水和同步节奏的说明。
- [Mayo Dragon Boat：比赛起步](https://mayodragonboat.com/2023/01/06/dragon-boat-race-start-fit-for-various-teams/)：参考从有力起桨逐步加速、再转入巡航节奏的过程。本项目把过程压缩到 26 秒展示，并未完整复现其起步桨数。
- [NVIDIA GPU Gems 第 1 章](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)：参考不同尺度水波叠加、根据高度梯度求法线、局部圆形扰动的思路。
- [Goby56/wakes 的波动模拟代码](https://github.com/Goby56/wakes/blob/main/src/main/java/com/goby56/wakes/simulation/SimulationNode.java)及[尾流节点代码](https://github.com/Goby56/wakes/blob/main/src/main/java/com/goby56/wakes/simulation/WakeNode.java)：阅读了移动水面扰动与随时间衰减的实现。该项目为 GPL-3.0，没有复制其源码；本工程另写了适合当前 OpenGL 程序的解析效果。

## 船桨与人物

两艘船共 24 支划桨，每支桨围绕握持位置运动。一周期用六个关键状态描述，在状态之间平滑插值：前伸、压桨入水、拉水、提桨、回桨、回到前伸。拉水时桨叶低于水面，回桨时抬离水面，并向外侧略微倾桨，避免桨叶下缘拖水。同船 12 名队员共用相位，两船分别累计相位。

人物沿用 MakeHuman CC0 模型。制作脚本在原始骨架上设置手掌 IK 目标，使上手握 T 柄、下手握桨杆，同时调整身体前倾、保持坐姿。每个周期烘焙 40 个姿态，程序在相邻姿态间插值，服装和皮肤一起变形。两队共用这份姿态数据，左右侧做镜像。

- `tools/bake_rowing_cycle.py`：制作及检查动作数据。
- `models/rowing_cycle.bin`：运行所需的姿态数据，不依赖 Blender。
- `models/rowing_cycle.json`：关键状态、帧数和闭合误差记录。
- `src/rowing.h`：读取姿态、插值并更新顶点缓冲。
- `src/race_motion.h`：桨的运动轨迹、桨频、速度与距离。

静态 OBJ、GLB 和原始建模场景仍用于保存造型。划桨动画由 C++ 程序及姿态数据共同实现。

## 两队的速度变化

红队起步较快；青队在中段提速并超过红队；红队后程冲刺，最后略微领先。速度曲线连续，先积分成距离，再按距离查询 Bézier 航线，不会因改变参数而突然跳位置。两船沿各自的航道前进，转弯时仍保留横向间隔，两条航道中心相距 4.1 米，回桨时两船的桨叶也保留间隙。

这是为短片设计的运动过程，速度、冲刺时机和领先变化由程序设定，不是实测比赛数据，也没有求解划桨推力与阻力。窗口左上角显示两船当前速度和桨频，便于演示差别。

相机继续沿独立空间曲线运动。注视点根据两船实际位置计算，而不是沿原来的匀速航线取点。

## 水面

古镇河面采用小幅风浪与天空反射。船尾扰动沿过去约 2.2 秒的实际航迹保留，转弯时尾流随旧航迹弯曲，逐渐扩散、变淡；船首两侧增加细弱的分水波。桨叶入水位置产生短暂向外扩散的水纹，并加入轻微漂移与不规则泡沫。水纹使用各船的入水时刻，与划桨相位对应。

水面效果写在 `shaders/phong.frag`，历史位置和入水事件由 `src/main.cpp` 传入。它属于解析法线与泡沫着色，没有求解流体方程，也没有把河面改成大幅海浪。

## 查看与验证

双击 `run.bat`，按空格播放；按 3 使用无人机视角，按 C 退出跟随后可自由观察。鼠标拖动会暂停航行，便于检查姿态；再次按空格继续。

`test.bat` 检查速度积分、领先变化、桨叶入水和回桨高度、周期闭合及 OBJ 部件分类。`bin/DragonBoat.exe --verify` 输出 32 张真实运行截图，包含入水、拉水、回桨，以及第 5、15、26 秒的两队位置。`results/runtime_validation.json` 保存本机验证结果。鼓手已补充交替敲击动作，旗面和五阶段镜头已完成，实时方向光投影已加入。

## 鼓手动作补充

鼓手保持面向船尾的坐姿。左右手在连续两次划桨中交替落槌，落槌时刻对应入水相位；每次击打后抬槌、回弹，再准备下一拍。鼓槌绕握持处转动，双手及手臂使用同一握持轨迹的 IK 烘焙姿态，身体只有轻微起伏，凳子保持固定。暂停航行时，敲鼓动作一起暂停。

`models/drumming_cycle.bin` 保存 40 个姿态；运行 `tools/bake_rowing_cycle.py --drum` 可在 Blender 后台重制。`src/race_motion.h` 中的 `drumPose`、`drumGrip`、`drumTip` 描述鼓槌轨迹；`src/main.cpp` 将鼓手与鼓槌分别绘制，随各船桨频播放。静态场景中原有的鼓手和鼓槌批次已拆分，首次运行会建立相应版本的缓存。

验证增加了左右落槌、抬槌高度、鼓面接触、周期闭合和凳子分类检查。实际运行的近景截图为 `results/verify_19.png` 至 `verify_21.png`。
