# 端午河岸模型说明

这套模型以灰瓦、旧木、浅色石材和红色节庆陈设作为彩绘龙舟的背景。建筑属于课程场景中的江南水岸风格组合，不对应某一处实测古建筑。

## 建筑和桥梁

民居正面由双扇木门和两侧格窗组成，补充门槛、门环、石台阶、墙脚石砖、侧墙百叶和山墙填充。屋面包含木基层、弧形瓦垄、瓦当、屋脊和起翘端部；瓦垄集中在少量网格中，便于程序加载。亭台为四柱开敞结构，增加柱础、分层木托架、纵横梁、长凳和侧栏。

石桥位于终点后方，沿河宽方向横跨水面。桥面采用缓拱曲线，桥下保留实际开口，拱圈分为独立石楔；桥面铺装、柱座、栏柱、柱头、扶手、桥台和入口台阶分别建模。

终点门架包含木柱、石柱础、斜撑、横梁和窄瓦顶。“端午竞渡”牌面在门架两侧分别设置UV。悬灯位于两侧，中央留出龙头、鼓手和旗帜的通过空间。

## 临水设施

8米长石岸模块含砌块立面、压顶石和铺装；常规段为断续低护石，桥口与码头开口段保留栏柱和横栏。南岸X=-12米处使用开口模块，与下水台阶和木码头连接，码头入口不被栏杆堵住。码头包含铺板、横梁、木桩、系缆柱和绳圈，末端与龙舟航道保留间距。芦苇包含茎、穗和弯折叶片，沿水线摆放。

## 节庆陈设

茶摊包含木柱、竹横梁、下垂布篷、木桌、拉撑及“粽香茶铺”牌面。桌上摆放竹编篮、包叶粽子、陶茶壶和茶杯。粽子为带绑线的三角锥外形；竹篮由篮底、编织圈、竖向竹篾和包边组成。篮子另提供独立OBJ。

灯笼包含灯体、竹骨、上下盖、吊绳和流苏。资产库另含石脚木凳及竹盆景。新增建筑、道具、纹理和牌面均由本工程脚本生成；开放资产的作者和许可见《开源参考与素材来源》。

## 文件约定

新增资产为 `quay_access`、`mooring_dock`、`riverside_bench`、`zongzi_basket`、`tea_stall`、`bamboo_planter`、`reed_patch`。已有建筑、桥、岸、灯和门架使用原文件名更新。OBJ使用Y轴向上，单位为米；实例摆放见 `models/scene_layout.json`。

先运行 `tools/make_riverside_textures.py`，再运行 `tools/build_models.py`。添加 `--environment-preview` 参数可在导出大型文件前仅生成四张环境近景。
