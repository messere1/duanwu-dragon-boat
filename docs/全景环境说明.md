# 360°全景环境

本次将原有古镇街区扩展为完整周边环境。沿河两端继续布置民居和后巷，接续石岸与铺装，村路通向外围田块和林带；河流在远处弯曲，地形与环绕山脊连接，天空由完整球面覆盖。

## 交付内容

- 追加的沿河街区和后排院落与原街区使用相同模型原型，保留实例关系。
- `panorama_terrain.obj`：连续地形与环绕山地。
- `panorama_farmland.obj`：随真实地形投射的田块和种植行。
- `panorama_streets.obj`：延伸的沿河铺装、水沟和村路。
- `panorama_sky.obj`：半径700米、法线朝内的完整天空球。
- 整体河段约840米，详细村镇集中于中央约160米的范围。最新版本从 X=28 米起进入下游 S 形河湾，地形、石岸、道路随河线调整，村外有冲刷河床、自然碎石岸和缓坡；具体见《河湾与无人机跟拍参考》。

天空使用已署名的Poly Haven Kloofendal 48d Partly Cloudy素材。2k源图由官方接口取得，作者Greg Zaal，授权CC0；下载地址和校验值保存在素材目录的 `sky_2k_source.json`。便携PNG由 `make_panorama_sky.py` 进行色彩转换生成。

## 查看方法

预览图15是2:1比例的等距柱状360°全景图，平面显示时会有投影变形。图16—19分别检查四个方向，图20为扩大范围的鸟瞰图。Blender源文件可以绕场景旋转查看；按Z后选择材质预览或渲染模式查看天空和表面贴图。

检查脚本从四个位置，每隔5°分别向水平、下方及上方发射射线。下方和水平射线要求在600米内命中实际地物，而不是依赖天空遮住缺口；上方射线要求被地物或天空覆盖。该范围覆盖主要竞渡镜头与环绕视角，不将有限场景解释为无限世界。

## 程序接入

天空材质标为 `sky_unlit`，GLB使用 `KHR_materials_unlit`。C++/OpenGL中应单独绘制天空背景，不参与模型自动归一化，也不对其使用场景物体的Phong明暗计算。原始OBJ/MTL没有统一的无光照语义，需要由材质名或场景清单识别。相机远裁剪面在Blender中设置为2000米；建议运行程序将天空作为独立背景通道处理。

主要街区、人物和龙舟仍采用米制尺寸。重复房屋与树木宜复用原型，避免把完整场景OBJ逐个零件作为独立绘制调用。

`360全景预览.html` 是离线预览入口，图像已内嵌，可以鼠标拖动环视。该入口显示固定位置拍摄的全景图，完整几何和相机移动仍在Blender源文件中查看。
