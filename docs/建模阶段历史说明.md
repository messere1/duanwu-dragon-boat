## 接入 C++ / OpenGL 的约定

1. OBJ 是 **Y 轴向上、X 轴正向为船头方向**，长度单位为米。所有面已三角化，并提供 `v/vt/vn`；材质由同目录的 `palette.mtl` 定义，图片位于相邻 `textures/`。
2. **不要对每个 OBJ 单独居中和归一化。** 船身、龙头和龙尾使用同一条船的原点，单独归一化会破坏装配。若沿用前两次作业的加载器，应保留原始位置和尺寸；在场景层统一变换。
3. `dragon_boat_*.obj` 适合整船移动；船桨动画使用独立模型及 GLB / Blender 层级；当前人物是静态姿态网格，如需四肢骨骼动画，使用 external_assets/makehuman_cc0/athlete_rigged_cc0.blend 中保留的原始骨架重新摆姿或导出骨骼数据。OBJ 的 `o` 分组保留几何部件名，但 OBJ 本身不能存储父子节点和骨骼动画。
4. 人物原点在座位或脚下，船桨原点在握持处，旗帜原点在旗杆底部。`scene_layout.json` 包含实例与父节点、本地矩阵及 Y-up 世界矩阵。Blender 内部采用 Z-up，本地矩阵字段 `local_matrix_zup` 需做坐标变换；世界矩阵已转换为 Y-up。
5. 红队原点为 `(-5, 0, 2.2)`，青队原点为 `(-6, 0, -2.2)`，终点位于 X=14。下游从 X=28 开始转弯，两座下游拱桥已移至 X=122 和 X=164，避开计划航程；另保留上游石桥。船只航线和无人机机位采用独立 Bézier 曲线，详见 `docs/河湾与无人机跟拍参考.md`。
6. 布料、叶片和中文牌匾含单层面，头发等材质还使用 PNG 透明通道，渲染这些材质时关闭背面剔除，或在着色器中处理背面法线。船身和桨叶有厚度。
7. 原始程序纹理同时提供 PNG 和 BMP；新引入的详细模型主要使用 PNG/JPG，包含透明通道、法线和粗糙度。后续 C++ 读取器应支持 PNG/JPG、MTL、多材质和透明度，不能直接沿用只读 BMP 的旧读取器。中文牌匾应使用原始 UV；其他部件为程序投影 UV。
8. 木石资产已带有法线与粗糙度贴图；水面法线和环境映射仍需在 OpenGL 中实现，当前离线水面材质不能替代课程的加分技术。
9. 弯曲后的地形、道路和石岸应使用完整场景 OBJ 的分组网格或 GLB 中的实际网格，不能仅用旧的直线单体加布局矩阵重建。单体 OBJ 仍用于后续复用和编辑。两艘龙舟保持独立装配，适合单独运动。

## 重新生成

安装 Blender 4.3 或兼容版本，以及 Python + Pillow 后，在 Project 目录执行：

```powershell
python tools/make_textures.py
python tools/make_boat_ornaments.py
python tools/make_riverside_textures.py
python tools/make_huizhou_textures.py
blender -b --python tools/make_panorama_sky.py
blender -b -t 8 --python tools/build_models.py
python tools/validate_models.py
blender -b --python tools/check_environment.py
blender -b --python tools/check_roundtrip.py
```

脚本会重新创建模型、GLB、Blender 源文件和二十张主要预览。已有 external_assets/prepared_open_assets.blend 时，重建场景不需要网络或 MPFB 插件；初次抓取、人物生成和资产预处理是额外步骤。材质、颜色、船体尺寸及河岸布局均可在脚本中修改；参数固定，输出可复现。

生成后会核对 OBJ 索引、三角面面积、法线方向、材质纹理路径、清单包围盒及场景层级引用，结果写入 `models/validation.json`。肩部与手臂接合位置在建模脚本中另有断言检查。

整船、完整场景 OBJ 和 GLB 还用 Blender 重新导入，核对几何、UV、材质及图片加载，结果见 `models/roundtrip_validation.json`。如需复查，可执行 `blender -b --python tools/check_roundtrip.py`。使用 `python tools/package_models.py` 可重新生成建模阶段压缩包。

开源项目的检索结果及素材来源见 `docs/开源参考与素材来源.md`。本目录包含注明来源和许可的开放模型及纹理，不包含 Blender 安装包或 MPFB 工具源码。

## 开放资产制作步骤

通常直接使用随附 prepared_open_assets.blend 重建即可。重新获取素材可运行 tools/fetch_open_assets.py 和 tools/fetch_human_assets.py；人物生成使用 MPFB 2.0.18，其源码应放在相邻 _work/dragonboat/mpfb2-2.0.18，所选 MakeHuman 资产放在 _work/dragonboat/makehuman_selected。随后依次执行 prepare_human.py、prepare_open_assets.py、build_models.py。导出模型使用时保留 docs/开源参考与素材来源.md，注明 CalWhite 的龙头与 CC BY 4.0 授权。
