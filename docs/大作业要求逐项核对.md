# 大作业要求逐项核对

核对对象为课程大作业截图中的要求，工程为端午竞渡龙舟场景。姚子辰负责建模和动画，报告由小组其他成员完成。本文件提供实现与证据索引，不代替实验报告，也不代表教师评分。

## 基础要求

| 原要求 | 核对结论 | 对应实现和证据 |
|---|---|---|
| 中国传统文化、致敬经典或时政主题，载入合适的 OBJ，场景有实际意义并兼顾美感，20 分 | 已实现 | 端午龙舟竞渡与皖南古镇河道；红青两船、桨手、坐姿鼓手、舵手、门楼、民居、石岸、桥、田野和生活道具组成完整环境。`models/scene_preview.obj` 在运行时实际加载，保留米制坐标、法线、UV 和多材质。`src/assets.h` 为加载代码，`results/runtime.log` 记录实际面数和贴图加载结果。美感部分由教师主观评价。 |

| Phong 光照与纹理贴图，20 分 | 已实现 | 反射向量形式的 Phong：环境光、漫反射、镜面反射；木板、石岸、人物、建筑、天空等材质接入实际图片。H、T 可分别比较光照和纹理效果；材质、纹理路径及运行截图有验证记录。 |

以上是基础项的实现覆盖情况，不能据此预先断定实际得分。

## 加分项

| 原要求 | 核对结论 | 演示与代码位置 |
|---|---|---|
| 高级纹理技术，每种 10 分，例举 bump mapping 或 environment mapping | 已实现法线贴图、环境映射 | `phong.frag` 从图片解码切线空间法线，利用位置和 UV 导数建立 TBN；木石纹理可按 N 比较。水面通过反射方向查询全景天空图片，并使用 Fresnel 权重，可按 V 比较。法线贴图不是顶点凹凸建模，也没有实现视差遮挡贴图；高级纹理具体如何计项由教师认定。 |
| 使用 Bézier 曲线控制物体运动路径，20 分 | 已实现 | `src/routes.h` 使用两段三次 Bézier 控制龙舟航线；`src/race_motion.h` 积分各队速度后换算航程，再按弧长表查询位置。整船随航线切线转向。相机另有分段三次 Bézier 航线，位于 `src/cinematic.h`。并非只有相机使用曲线、船仍直线平移。 |

## 建模和动画的交接材料

- 完整可编辑造型：`dragonboat_models.blend`。其中保存静态装配与材质，运行时动画由 C++ 实现。
- 通用场景：`models/dragonboat_scene.glb`；运行时完整 OBJ：`models/scene_preview.obj` 和 `palette.mtl`。
- 图片：`textures`。不要只交 OBJ 而漏掉 MTL 或贴图。
- 人物动作：`models/rowing_cycle.bin`、`drumming_cycle.bin` 及各自 JSON 验证记录。不要漏交这些运行依赖。
- 动作制作：`tools/bake_rowing_cycle.py`；播放：`src/rowing.h`、`src/race_motion.h`、`src/main.cpp`。
- 旗帜：`shaders/phong.vert`；水面：`shaders/phong.frag`。
- 键鼠、镜头和验证说明：`docs/OpenGL运行与操作说明.md`、`划桨变速与水面实现.md`、`旗帜与镜头验收.md`。
- 素材署名和修改记录：`docs/开源参考与素材来源.md`。龙头、人物和部分环境素材来自开放授权资产，应在报告中据实引用，不能全部写成从零原创建模。

## 已完成的验收

`models/validation.json` 记录 57 个 OBJ 的索引、有限坐标、UV、单位法线、非零面积、材质路径与场景引用检查。此次旗帜和镜头修改没有改写这些静态模型。

当前 `results/runtime_validation.json` 为 PASS：32 张实绘检查图、完整连续播放 302 帧、动画时间 26 秒、OpenGL 错误数 0。检查覆盖模型平移缩放旋转、两种鼠标操作、Tab 选船、暂停、额外 OBJ 导入、光照纹理比较，以及划桨、敲鼓、旗帜与五阶段镜头。

`results/cinematic_geometry_audit.json` 记录 1,561 个相机位置和 12,488 条观察射线；所查建筑、桥、地形、河岸等未挡住检查点，龙舟到河岸最小余量约 1.02 米。透明树叶未作为不透明障碍参与此项检查，不能把此结果扩大为每一个像素都无遮挡。

实时方向光投影现已实现；流体动力学和布料物理求解未实现，截图中的评分要求没有将它们列为必做项。
