# 皖南古镇风格环境修订

原场景的独栋建筑间距较大，岸边栏杆和铺装过于整齐。这次改动以皖南民居的白墙黛瓦、马头墙与院落关系为设计参考，重新组织沿河街面、后巷和屋群，保留竞渡所需的河道空间。

## 建筑与空间

核心街区布置33座民居，使用单层民居、双层民居、茶行和天井院落四种原型，局部调整位置、层高及朝向。前后两排屋面高低错落，建筑之间留出巷口。阶梯式防火墙采用完整的封闭网格，顶部有深色压顶；天井由四面厢房和屋面围合，中央实际敞开。

民居增加石门框、滴水门罩、木格窗、深门洞、门槛和旧木构件。部分茶行沿街设置布棚和木撑。亭台留在一处较小的公共空地，周边由民居围合。

## 岸线与生活细节

多数连续装饰栏杆改为低矮、断续的石护岸。石岸使用两种不同的模块，台阶位置有所变化，石阶下方延伸为实体砌体，一直进入水下。桥口和码头仍保留通行开口。

大块石板采用错缝和不完全规则的边缘；沿街设置浅水沟、石沟沿和过沟踏石。门口分布陶缸、柴堆、盆栽，后巷增加晾衣架，茶摊继续保留。陈设有疏有密，不在每扇门前重复放同一种盆景。

## 材质和背景

墙面采用多尺度明暗变化，并按高度叠加墙脚受潮、细雨痕和少量裂缝；瓦面以较低对比度的灰色变化表现旧瓦，避免颗粒过重。临水石材整体加深，石板缝隙带有灰绿调。纹理均由工程脚本生成。

河流及岸地向场景两端延伸，避免在赛道附近直接截断。远处加入连续丘陵、村边植被和林带；近景树木仍使用已署名的Poly Haven资产。远景树冠使用独立叶片网格，避免对带透明叶片的树木进行过度简化而丢失树冠。

## 参考与范围

- [黄山市人民政府：徽州宅居](https://www.huangshan.gov.cn/zjhs/rwhz/fsmq/8294878.html)：院落、天井及防火墙的空间关系。
- [中国非物质文化遗产网：徽派建筑艺术的内在意蕴](https://www.ihchina.cn/project_details/8202/)：马头墙形态及徽州民居的建筑特征。

这是一套面向课程竞渡动画的艺术化场景。房屋和街道没有采用某处古村的测绘尺寸；既有龙舟和坐姿鼓手装配在本次环境更新中保留。

新增脚本：`make_huizhou_textures.py`、`style_huizhou.py`、`update_huizhou_environment.py`。整体、沿街、天井和石岸近景分别为预览图11至14。源文件和GLB保留建筑实例层级，程序接入时可复用房屋原型，减少几何数据重复。

全景版本在此基础上继续延伸上下游，两岸共85座民居、14处天井，并连接田块和外围山林；完整范围见《全景环境说明》。
