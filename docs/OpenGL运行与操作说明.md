# OpenGL 程序：运行说明

当前工程已经可以独立运行古镇场景、两艘龙舟和下游河湾，支持键鼠控制，以及沿独立空间曲线移动的无人机视角。场景由真实 OBJ、MTL 和图片贴图加载，使用顶点、片元着色器绘制；不是播放建模预览图片。

## 编译与启动

直接双击工程根目录的 `run.bat`。已有 `bin/DragonBoat.exe` 时直接启动；没有程序时会调用 `build.bat` 编译。

使用 Visual Studio 2022 时打开 `DragonBoat.sln`，选择 **Release / x64**，生成并运行。需安装“使用 C++ 的桌面开发”和 Windows SDK。程序仅使用 Windows 自带的 Win32、OpenGL、WIC 图片解码组件，不需要另行配置 GLFW、GLEW 或图片库。

本机使用 MinGW-w64 GCC 7.3 编译并运行验证。`build.bat` 会先查找 MSVC，未找到时使用 PATH 中的 g++。也提供 CMake 项目，目标输出目录统一为 `bin`。

首次启动会读取较大的完整场景 OBJ 并生成 `cache/scene-v4.bin`，加载进度显示在窗口标题中。本机首次约 49 秒，之后缓存加载约 7 秒，速度取决于硬盘和显卡。修改 OBJ 或 MTL 后会重新生成缓存；缓存可删除后重建。建模时的原始米制坐标会保留，场景部件不会分别居中或归一化。

## 操作

| 按键或鼠标 | 功能 |
|---|---|
| 1 / 2 / 3 / 4 | 古镇全景 / 龙舟近景 / 无人机跟拍 / 内陆聚落 |
| 空格 | 开始、暂停或继续 26 秒航行演示；首次开始会进入无人机视角 |
| C | 独立跟拍与自由相机切换 |
| R | 重置航行时间、模型变换及相机 |
| 鼠标左键拖动 | 保持视点位置，改变观察方向 |
| 鼠标右键拖动 | 保持观察方向，平移视点 |
| 鼠标滚轮 | 相机沿视线前进或后退 |
| W / S / A / D，Shift | 自由相机前后左右移动，Shift 加速 |
| Tab | 选择红队、青队或额外导入的模型 |
| 方向键，PageUp / PageDown | 选中模型沿水平面或竖直方向平移 |
| Q / E，I / K，J / L | 选中模型绕 Y、X、Z 轴旋转 |
| + / - | 选中模型放大、缩小 |
| T / H | 开关图片纹理、Phong 光照 |
| N / V | 开关木石法线贴图、水面环境映射 |
| B | 开关方向光投影 |
| F | 线框显示 |
| O，或拖入 OBJ | 额外加载模型，读取其 mtllib 引用的材质文件；整体适配为便于观察的大小 |
| F12 | 将当前窗口保存为 PNG，位于 results 目录 |
| F1 / Esc | 操作帮助 / 退出 |

鼠标拖动时会暂停航行并切到自由相机，方便检查“模型固定、相机变化”的操作效果。键盘的模型变换作用于当前选择的模型，与相机操作分开。

## 当前实现

- `src/assets.h`：OBJ 三角形、凸多边形、负索引、UV、法线、MTL 及二进制缓存。
- `src/gpu.h`：索引顶点缓冲、WIC PNG/JPG/BMP 加载及 PNG 截图。
- `src/routes.h`：两段三次 Bézier 航线、独立的空间相机曲线与弧长采样。
- `src/main.cpp`：Win32 窗口、输入、相机、模型变换、时间轴和绘制批次。
- `shaders/phong.vert`、`phong.frag`：逐片元 Phong 光照、法线贴图、水面波动法线、天空环境映射与远景雾。

完整场景约 794 万个三角面，按材质及动作部件合并绘制批次（划桨人物和鼓手另用共享姿态重复绘制），避免逐个建筑零件发起绘制。红、青两队作为独立模型变换。场景采用 Y 轴向上，船头为 +X；建模阶段 Z-up 路线按 `(x, z, -y)` 转换后使用。

两艘船按各自航行参数移动并随航线转向。相机的位置来自另一条空间曲线，持续看向稍靠前的航线目标，包含横向位移、升降与拉远。已加入 24 支划桨、人物手掌 IK 烘焙姿态、两队不同的加速与冲刺节奏、尾流和桨边水纹。相机注视点跟随两队实际位置。细节见《划桨变速与水面实现.md》。鼓手已加入手臂与鼓槌配合的交替敲击，旗面已加入顶点飘动，镜头按五个阶段连续飞行。详见《旗帜与镜头验收.md》。

## 验证记录

`test.bat` 检查 OBJ 负索引与凸多边形三角化、UV 和材质引用、坐标保留、缓存失效、Bézier 端点及弧长速度、独立相机路线和坐标转换。

运行 `bin/DragonBoat.exe --verify` 会检查着色器和纹理加载、各比较开关、键盘平移缩放旋转、两种鼠标操作、额外 OBJ 导入，并以固定时间步推进完整 26 秒航线。它输出测试画面和 `results/runtime.log`，不是动画成片。

本机使用 OpenGL 4.6 / RTX 3050，当前加入人物与尾流后的同步帧耗时见 results/runtime_validation.json；首次切换场景包含驱动着色器预热，耗时较长。正常运行帧率以窗口显示为准。当前已加入实时方向光投影与四倍 MSAA；不能把 Blender 离线渲染图当作程序运行结果。

完整连续播放检查可运行 `bin/DragonBoat.exe --playthrough`，播放到 26 秒后自动退出并保存日志及六张截图；这不是成片录制。正常演示请使用 run.bat，再按空格播放。
