## 文件与复现

- `external_assets/manifest.json`：来源、作者、授权链接和下载文件校验值。
- `external_assets/*/source.json`：官方 API 元数据。
- `external_assets/prepared_open_assets.blend`：统一单位、简化网格、调整人物姿势后的资产库。
- `external_assets/makehuman_cc0/athlete_rigged_cc0.blend`：可重新摆姿的人物及骨架。
- `external_assets/makehuman_cc0/`：所用 MakeHuman 原始资产、纹理和文件内授权声明。
- `tools/fetch_open_assets.py`、`fetch_human_assets.py`：下载和校验工具。
- `tools/prepare_human.py`、`prepare_open_assets.py`：体型生成、服装权重、摆姿和简化。
- `tools/style_open_assets.py`：场景装配及实拍材质适配。
- `tools/style_ceremonial_boat.py`：新版船体、龙头变形裁切、彩绘、雕花、船肋、坐板与甲板设计。
- `tools/make_boat_ornaments.py`：自行绘制的鳞纹和莲花纹带，按船侧的长宽比例制作，并沿船壳曲面贴合。

[MPFB 2.0.18](https://github.com/makehumancommunity/mpfb2) 是人物制作工具，源码放在工程外 `_work` 目录，不是课程程序的运行依赖；MakeHuman 核心资产的 CC0 授权与工具源码的授权分别处理。

## 未采用的候选

Gilded Dragon Boat 的作者说明标注为 Meshy 生成；Dragonboat1 预览不完整；部分博物馆扫描模型带有禁止修改条款；Wooden Seadragon Boat 的文化形制与场景不符。这些模型均未用于交付。

早期查询过 SolaceLabs/demo-dragonboat、JUST0M/procedural-buildings 等代码项目，没有复制其代码；它们不是当前模型来源。

## 渲染阶段

预览由 Blender 离线渲染。颜色、法线和粗糙度纹理已保存，GLB 保留材质连接，OBJ/MTL 保留颜色及适用的法线、透明度引用。C++ 程序现已实现 OpenGL Shader、Phong、水面波动法线、天空环境反射和划桨动画，实际运行截图位于 results；它们与 Blender 离线预览分别保存。

## 新版船体设计依据

造型参考[中国非物质文化遗产网的龙舟制作技艺介绍](https://www.ihchina.cn/project_details/14577/)中对龙骨、横挡、坐板等结构的说明，以及[福建省政府介绍的龙舟彩绘装饰](https://www.fujian.gov.cn/zwgk/ztzl/sxzygwzxsgzx/sdjj/wvjj/202406/t20240626_6473756.htm)。本模型是课程场景的综合设计，不是某一地区、某一实物龙舟的精确复原。新版由船壳上翘延伸到雕刻龙颈，结构相互搭接，并使用相同色系漆面；去掉上一版独立支撑块的拼接方式。
