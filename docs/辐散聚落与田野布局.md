# 村镇与田野布局调整

原有场景主要由两岸沿河街面和整排农田组成，容易出现带状排布和规则网格的感觉。这次保留部分临河老街，将后排及部分沿河民居移向内陆，形成八处疏密不同的小聚落。聚落之间用岔路连接，房屋朝向略有变化，外围逐渐过渡到田地和树林。

坡地住宅采用低石基和顺接地形的土台，地面在房屋周围逐渐回到原有坡面。巷道和田埂按实际地面高度采样。已有龙舟、河湾、终点设施和传统民居部件继续使用。

田野由非规则多边形地块组成，地块大小、退界距离和边数各不相同，间留空地、荒地与通行缝隙。作物行根据局部坡向调整方向；耕地、裸土与不同深浅的植被地块混合分布。地块避开住宅周围，避免田地穿进院落。

完整场景以 `dragonboat_models.blend`、`models/dragonboat_scene.glb` 和 `models/scene_preview.obj` 为准；单体 OBJ 为部件库，不能把旧田地模块再次叠加到完整场景。新增布局和田块边界保存在 `models/dispersed_layout.json`；本次脚本为 `tools/spread_village.py`，修改前备份保存在工程外的 `_work/dragonboat/before_dispersed_village`。

查看 `previews/25_dispersed_village.png` 的俯视整体，以及 `26_inland_village.png` 的内陆村落近景，可检查村镇纵深、地块变化和路径衔接。
